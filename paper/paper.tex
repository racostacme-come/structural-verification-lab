\begin{abstract}
Can a shared material and geometry definition expose inconsistent error levels between static beam compliance and elastic buckling? This software-methods paper consolidates 6 existing research implementations into a self-contained laboratory and adds a connected numerical experiment. Source snapshots, licenses, tests and original papers are retained with commit-level provenance and file hashes. The contribution is explicit interface verification and reproducible orchestration, rather than a new numerical method or a claim of physical validation. The reported experiment distinguishes shared-model consistency from numerical error and documents where component assumptions prevent further automatic coupling.
\end{abstract}
\section{Research scope and architecture}
Beam discretization, stability, nonlinear equilibrium, plasticity, adaptive meshes and boundary enforcement. The included implementations are shearscope, bucklemap, foldtrace, yieldledger, meshbeacon, boundarybalance~\cite{m0,m1,m2,m3,m4,m5}. Each remains a separately installable Python package; native C++ kernels retain their package-specific interfaces. The root runner builds the modules, executes tests in separate processes, checks imported file hashes and produces the new integration report. This process avoids test-module name collisions and makes failed checks visible instead of treating a directory collection as validated integration.
\section{Governing model and connecting assumptions}
For a uniform cantilever of length $L$, bending rigidity $EI$ and shear rigidity $S=\kappa GA$, the small-displacement tip compliance under a unit force is
\[
C_T=\frac{L^3}{3EI}+\frac{L}{S}.
\]
The Euler--Bernoulli cantilever critical load is $P_E=\pi^2EI/(4L^2)$. These different beam theories share a bending-only scalar identity,
\[
\frac{P_E}{L}\left(C_T-\frac{L}{S}\right)=\frac{\pi^2}{12}.
\]
Subtracting the shear term is essential: the identity does not equate the complete stiffness matrices or establish a shear-deformable buckling theory. ShearScope supplies full- and reduced-quadrature Timoshenko compliance; BuckleMap supplies Hermite finite-element Euler loads.
\section{Reproducible experiment}
The original implementations are reused through public Python APIs, including their separately compiled C++ element kernels. The new adapter creates a one-metre cantilever with width 0.02 m, height 0.01 m, Young's modulus 70 GPa, Poisson ratio 0.3 and shear correction 5/6. Both solvers receive the same length and bending rigidity. Four meshes (4, 8, 16 and 32 elements) are compared. Static error uses the independent closed-form Timoshenko compliance; load error uses the Euler cantilever formula. The product check measures cross-model parameter consistency. Run \texttt{python suite.py experiment} after installing the suite to regenerate the machine-readable results. All table entries below are generated from that report; no numerical result is copied from a component paper. Component source commits and per-file hashes are stored in the suite manifest. The experiment and integration test are versioned alongside this manuscript.

\section{Verification and limitations}
The root test command runs each component's Python tests and the shared-model contract tests, recording return codes and complete output. Independent tests check modulus and geometric scaling, and refinement toward the analytical beam limits at slenderness ratios 20 and 100. C++ extensions are compiled during installation. A separate \texttt{native} command builds and executes the four C++17 invariant tests through CTest. Cross-platform CI runs both test commands; sanitizer, distribution and full historical reproduction campaigns are outside this gate. The paper build rejects unresolved references, overfull boxes and manuscripts over five pages. Imported bytes use explicit file hashes; a documented line-ending repair and one attributes-file patch make the provenance gate portable without changing numerical source.

The common experiment is linear, slender and uniform, with ideal clamping. It does not connect plasticity to buckling, trace post-buckling branches, establish nonlinear stability, or validate a physical beam. Refinement evidence applies to the chosen meshes and material scaling. The imported modules support additional independent experiments, but their historical results are not new integration measurements.
\section{Conclusion}
The integrated repository supplies a common execution and evidence interface while preserving the assumptions that make each numerical component interpretable. The connected experiment makes a specific cross-component contract testable. Further coupling should be treated as new research work, with independently derived reference cases and a revised paper, rather than inferred from successful package installation.
