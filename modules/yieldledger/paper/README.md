# Academic manuscript

[PDF](paper.pdf) | [LaTeX](paper.tex)

From the repository root, after installing development dependencies:

```bash
yieldledger --output results
python paper/build.py --engine pdflatex
# Alternatively: python paper/build.py --engine /path/to/tectonic
pdftoppm -r 120 -png paper/paper.pdf paper/build/page
```

Uses standard LaTeX packages: article, geometry, amsmath, amssymb, graphicx,
booktabs, lmodern, microtype, hyperref. The builder runs pdfLaTeX twice or lets
Tectonic resolve references. More than five pages, blank pages, overfull boxes
or undefined citations/references fail the build. Numerical macros are generated
from committed metrics. Validation records SHA-256 hashes of source, figure,
metrics, CSV data and implementation. CI uploads its independent PDF and report.

The figure is generated by the original experiments; no course images or data are
used. A page-count check is supplemented by rendering and visual review of every
page. This manuscript documents synthetic mathematical verification, with no
claim of affiliation, peer review, novelty or physical material calibration.
